# RimDark 40K - Ranks Of The Imperium

Development repository of the `Ranks Of The Imperium` mod for RimWorld.

If you install the mod from here, it have a different id than the one on Steam but you can't use them simultaneously.

Check the [releases](https://github.com/khoeos/RimDark-40K-Ranks-Of-The-Imperium/releases) for stable versions.

## Description

This is an unofficial addon for [Rimdark 40k](https://github.com/Phonicmas/Rimdark40kFramework) that add various ranks around the imperium / Astra Militarum.
